# 🎬 CineVerse — OTT Streaming Website

CineVerse is a modern frontend OTT streaming website designed to provide an attractive movie and series browsing experience.

The project is built using **HTML, CSS, and JavaScript** with a focus on responsive design, animations, interactive movie cards, search, categories, watchlist functionality, and a modern streaming-platform interface.

---

## 📌 Project Overview

**Project Name:** CineVerse  
**Project Type:** Frontend Web Application  
**Category:** OTT / Movie Streaming Platform  
**Development:** HTML + CSS + JavaScript

CineVerse provides users with a visually attractive interface where they can explore movies and series, view movie information, manage a watchlist, change themes, and interact with different sections of the website.

---

## 🎯 Project Goals

The main goals of CineVerse are:

- Create a modern OTT-style interface
- Build a responsive website
- Add smooth animations and visual effects
- Display movies and series dynamically
- Implement search functionality
- Add category filtering
- Create a watchlist system
- Store user preferences using Local Storage
- Improve frontend JavaScript skills
- Practice Git and GitHub version control
